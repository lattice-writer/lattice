# Lattice 使用指南

Lattice 是一款 Mac 上的 LaTeX 和 Typst 论文写作应用。论文始终是磁盘上的普通文件夹；Lattice 在旁边加上 PDF、论文库与引用、版本历史、Overleaf 同步和 AI 助手。

本指南介绍 Mac 上的 Lattice，按任务分页，每页讲一件事。Lattice 更新频繁，指南会随每个版本一起更新；**帮助 › Lattice 新功能** 列出当前版本的改动。在 Lattice 中可以从 **帮助 › 使用指南** 打开本指南。English: [Lattice User Guide](../README.md).
