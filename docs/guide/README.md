# Lattice User Guide

Lattice is a writing app for LaTeX and Typst papers on the Mac. Your paper stays an ordinary folder on disk; Lattice adds the PDF beside it, your papers and citations, version history, Overleaf sync and an AI agent.

This guide covers the main tasks, one page each, for Lattice on the Mac. Lattice ships often, so the guide is updated with every release; **Help › What's New in Lattice** lists what changed in the version you run. Lattice's own menu opens it from **Help › User Guide**. 中文版：[Lattice 使用指南](zh-CN/README.md)。
