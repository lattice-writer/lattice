    Lattice User Guide

    Lattice is a writing app for LaTeX and Typst papers on the Mac. Your paper stays an ordinary folder on disk; Lattice adds the PDF beside it, your papers and citations, version history, Overleaf sync and an AI agent.

    This guide covers the main tasks, one page each, for Lattice on the Mac. Lattice ships often, so the guide is updated with every release; Help › What's New in Lattice lists what changed in the version you run. Lattice's own menu opens it from Help › User Guide. 中文版：Lattice 使用指南。

    Getting started

    • Getting started: install Lattice and TeX, open or create a project, the Get started checklist.
    • Panels and workspaces: arrange panels, save layouts, rename or delete a workspace.

    Writing

    • Writing: the editor, Source and Visual, outlines, code files and notes.
    • Boards: whiteboards in your project.
    • History and Compare versions: undo any change, save versions, compare two of them, track changes.

    Building and PDF

    • Building and fixing errors: ⌘S, the PDF beside your source, build problems, auxiliary files, exporting.
    • Typst documents: write and build .typ files.

    Citations and Papers

    • Citations and papers: ⌘⇧K and ⌘⇧L, the Papers library, Zotero, Check references.

    Agent

    • The Agent: Claude Code, Codex or your own model, working on your paper.

    Overleaf

    • Overleaf sync: open an Overleaf project, upload one, how sync behaves.

    Settings

    • Settings and shortcuts: where each setting lives, the keys worth learning.
    • Plugins and themes: themes, code themes, install a plugin.

    Troubleshooting

    • Troubleshooting and FAQ: what to try when something goes wrong, and how to report it.

    Developing plugins

    For people who want to write a plugin or a theme and list it in the Lattice market.

    • Your first plugin: build a hello-world plugin, run it from its folder, read its logs.
    • Plugin manifest and API: permissions, calling Lattice, results and actions.
    • Publishing a plugin: reproducible packs, the registry pull request, review, signing, updates and the kill switch.
    • Making a theme: write a lattice-theme.json, try it, publish it.

    Screenshots show Lattice in light mode, with the bundled tutorial paper open. Your window may differ slightly by version and theme. On Windows and Linux, Lattice is still the classic app, which looks much the same but differs in places this guide doesn't cover.
