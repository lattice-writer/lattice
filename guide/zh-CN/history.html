    历史与版本对比

    Lattice 记录项目里的每一处改动，不管是你、AI 助手，还是 Overleaf 上的合作者改的。点标题栏的 项目历史 按钮（时钟图标），或在命令面板（⌘K）里运行 项目历史 打开。

    撤回改动

    历史有三个视图，关联了 Overleaf 的项目有四个：

    • 全部 按时间倒序列出所有改动：你的、AI 助手的、保存的版本和 Overleaf 上的更新。
    • 动态 列出 Lattice 自己的编辑和 AI 助手的每轮操作，可以按 全部、你、AI 助手 或 引用 筛选。AI 助手的一轮操作可以用 撤销 AI 改动 整体撤回。
    • 版本 列出你保存的版本（见下文）。
    • Overleaf 列出来自 Overleaf 的更新，只在关联的项目中出现。

    点一条查看差异，再点 恢复文件，把文件恢复到这次改动之前的样子。恢复本身也是一条新记录，同样可以撤回。

    保存版本

    命名版本基于 Git。第一次使用时，版本 页会提示 记录版本，把项目变成一个 Git 仓库（已经是仓库的项目直接使用）。之后：

    • 保存版本：用你起的名字记录项目当前的状态。
    • 每个版本都有 与现在对比 和 恢复此版。

    版本对比

    点历史工具栏上的 对比…，然后在 起 和 止 中选两个版本（现在 指磁盘上的当前项目）。Lattice 列出所有改动过的文件。正文 显示改动的词，读文字更方便；源码 显示逐行差异。

    导出修改对照 PDF… 通过 TeX 发行版中的 latexdiff 生成一份标出差异的 PDF。使用 BasicTeX 时，可能需要先运行 sudo tlmgr install latexdiff。

    跟踪修订

    标题栏的 跟踪修订 按钮打开审阅模式：从此之后你的修改都会在源码中标出来（按钮随之变成 停止跟踪修订）。审阅栏用 上一处改动 和 下一处改动 逐条跳转，并有 接受、拒绝、全部接受、全部拒绝 和 在 PDF 中显示改动。不需要 Overleaf 也能用。
